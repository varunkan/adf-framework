# URL Shortener App

## Running the App
1. Save all files in the same directory.
2. Run the server using `python3 server.py`.
3. Open a web browser and navigate to `http://localhost:8000`.
4. Enter a URL in the input field and click the "Shorten" button.
5. The shortened URL will be displayed below the input field.

## Running the Tests
1. Run the tests using `python3 test_app.py`.
2. The tests will start the server in a background thread and test the API endpoints.
3. If all tests pass, you should see an output indicating success.

Note: Make sure to run the server and tests in the same directory where the files are saved.
