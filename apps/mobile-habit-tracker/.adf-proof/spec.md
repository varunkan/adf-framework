## Requirement
# Mobile Habit Tracker

A simple cross-platform mobile app (iOS + Android) to track daily habits.

- The home screen lists the user's habits, each showing its name and current streak.
- The user can add a new habit (name) and delete a habit.
- Tapping a habit opens its detail screen showing the streak and a button to mark it done for today (which increments the streak).
- Data is stored locally on device (no server, works offline).
