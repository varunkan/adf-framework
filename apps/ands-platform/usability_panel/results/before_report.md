## Qualitative themes per flow

### AI-assisted document drafting chat (ANDS Studio dossier builder)

Here are the dominant themes, ordered by frequency:

1. **Clear Indicators and Feedback** (8)
   - Short name: Clarity
   - Representative quote: "I'd like to see more explicit indicators for required and optional sections, and perhaps a more intuitive way to navigate the section tree."
   - Concrete product change: Add a prominent badge or tooltip to indicate which sections support AI drafting.

2. **Audit Trails and Version Control** (5)
   - Short name: Audit
   - Representative quote: "I'd also like to see a more prominent warning about the potential risks of using unvalidated AI-generated content in a regulatory submission."
   - Concrete product change: Implement a clear audit trail for AI-generated content, including version control and change history.

3. **AI Drafting Interface and Customization** (6)
   - Short name: AI Interface
   - Representative quote: "I'd like to see more explicit controls for customizing the AI's output, such as the ability to insert specific phrases or terminology."
   - Concrete product change: Add a customizable template feature for AI drafting, allowing users to specify formatting and content requirements.

4. **Error Messages and User Experience** (5)
   - Short name: Error Messages
   - Representative quote: "I'd change the 'AI drafting isn't set up yet' message to be more actionable and provide a clear call to action for the user or administrator to configure the AI backend."
   - Concrete product change: Improve error messages to provide clear instructions and actionable next steps.

5. **Integration with Existing Tools and Systems** (3)
   - Short name: Integration
   - Representative quote: "I'd like to see more integration with our existing validation tools, such as LORENZ docuBridge."
   - Concrete product change: Integrate AI drafting with existing tools and systems, such as eCTD platforms, to streamline the submission process.

6. **Transparency and Trust** (3)
   - Short name: Transparency
   - Representative quote: "I appreciate the idea of an AI-assisted drafting tool, but I'd like to see more transparency about how the AI is trained and validated."
   - Concrete product change: Provide clear explanations and examples of the AI's training and validation processes to increase user trust and confidence.
