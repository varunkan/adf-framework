## Approach

- Model each original URL with a hashed, alphanumeric key; store the mapping in DB or cache.  
- Provide REST endpoint `POST /shorten` that receives full URL, computes hash, creates entry, returns short code (e.g., `https://app.com/abc123`).  
- Front‑end page displays form, calls `/shorten`, displays result, and on click redirects user to original via 301.  
- Automated tests verify hash uniqueness, redirect behavior, and graceful fallback for invalid requests.
